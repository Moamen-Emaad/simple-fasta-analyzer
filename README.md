# Simple FASTA Analyzer

A beginner-friendly bioinformatics project written in Python using only built-in features, without external libraries.

## Features

- Read DNA sequences from FASTA files.
- Calculate sequence length.
- Calculate GC content.
- Count A, C, G, T, N, and other characters.
- Display results in a formatted table.
- Export sequence summaries to CSV files.

## Requirements

- Python 3
- No external Python libraries required.

## Usage

Run the script:

```bash
python3 simple_fasta_analyzer.py
```

Enter the path to your FASTA file when prompted.

The script displays a summary of the sequences and saves the results to a CSV file.

## Learning objectives

This project practices Python fundamentals, file handling, string manipulation, functions, dictionaries, and basic DNA sequence analysis.

## Limitations

This is a basic sequence analyzer, not a complete FASTA validation tool. Characters outside A, C, G, T, and N are counted as other characters.
